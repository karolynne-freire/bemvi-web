# 🌿 Bemvi Web

> **No Bemvi, você não fala sozinha.**

O **Bemvi Web** é a interface web de uma plataforma digital de acolhimento, orientação e conexão voltada para mães atípicas. Desenvolvido com React, o projeto busca proporcionar uma experiência acessível, intuitiva e humanizada, facilitando o acesso a redes de apoio, profissionais especializados e espaços inclusivos.

A aplicação faz parte do ecossistema Bemvi, idealizado a partir de pesquisas com mães atípicas e dos princípios de Design Centrado no Usuário (DCU) e Interação Humano-Computador (IHC).

## 🎯 Objetivo

Criar uma experiência web que ajude mães atípicas a encontrar apoio emocional, compartilhar experiências e acessar informações relevantes para o cotidiano de suas famílias.

## ✨ Funcionalidades previstas

- **Rede de apoio:** salas temáticas para interação e compartilhamento de experiências entre mães.
- **Profissionais Bemvi:** busca e indicação colaborativa de profissionais da saúde e da educação.
- **Mapa de Inclusão:** visualização de locais acessíveis e inclusivos.
- **Perfil da usuária:** gerenciamento de informações pessoais e preferências.
- **Acessibilidade:** opções de personalização visual e navegação inclusiva.

> As funcionalidades serão disponibilizadas conforme a evolução do desenvolvimento.

## 📋 Pré-requisitos

Antes de executar o projeto, instale:

- [Node.js](<https://nodejs.org/>), preferencialmente uma versão LTS compatível com as dependências.
- npm, incluído na instalação do Node.js.
- [Git](<https://git-scm.com/>).

## 🚀 Como executar o projeto

### 1\. Clone o repositório

```
git clone https://github.com/karolynne-freire/bemvi-web.git
```

### 2\. Acesse a pasta do projeto

```
cd bemvi-web
```

### 3\. Instale as dependências

```
npm install
```

### 4\. Inicie o servidor de desenvolvimento

```
npm run dev
```

Se o projeto utilizar Vite, a aplicação estará disponível no endereço indicado pelo terminal, normalmente `http://localhost:5173`.

> Os comandos dependem da configuração real do projeto. Caso seja utilizada outra ferramenta de inicialização, como Create React App, as instruções deverão ser ajustadas.

## ♿ Acessibilidade

O desenvolvimento considera as diretrizes WCAG como referência para promover uma experiência inclusiva, contemplando:

- Contraste adequado entre textos e fundos.
- Navegação por teclado.
- Compatibilidade com leitores de tela.
- Hierarquia semântica dos elementos.
- Layout responsivo e legível.
- Interface intuitiva e redução da sobrecarga cognitiva.

## 🔒 Privacidade e segurança

Recursos relacionados a perfis, conversas e informações pessoais deverão considerar a proteção de dados e a privacidade das usuárias.

O desenvolvimento deverá observar boas práticas de segurança e a legislação aplicável, incluindo a Lei Geral de Proteção de Dados Pessoais (LGPD).
